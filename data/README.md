# DeepKamal database

File: `deepkamal.db` (SQLite)

Created automatically when you run:

```bash
npm run start:clean
```

Check it:

```bash
npm run db:check
```

Or open http://localhost:3000 → sign in as Owner → **Database** in the sidebar.

**Important:** The app must be opened at `http://localhost:3000` from `npm start`.  
Opening `index.html` directly or via VS Code Live Server will look like the “database is not working” because there is no API.
